### 3.3 推理强度和图片（S48/S49，少量费用）

1. 默认推理强度：主模型旁的下拉，只出现"服务商默认"和该模型支持的档位（Flash-Lite 是 minimal/low/medium/high；minimal 不是关闭）。
2. 选一个档位，重启后还在。
3. 会中把"本次会议推理强度"改成另一个档位，设置页的默认值不变；会议结束后会中值清除。
4. 会中把模型换成另一个型号再换回来，推理强度显示正确，没有乱跳。
5. 截图提问一次，两个模型都应该能发图。
6. 这一项不能判断参数有没有真正生效：服务端接受参数，不等于真按这个强度推理。只记录回答速度和内容的大致差异即可。

### 3.4 真实会议和回答（清单 B1、B3、B4）

1. 冷启动到启动器出现，不卡；没有重复的权限提示。（B1）
2. 先在语音设置里清空 Groq，开始会议应该被拒绝，并告诉你去哪里配置；然后再配回来。（B1）
3. 开一场会议，自己说话，同时播放一段视频或会议录音：两路转写都出现，并且分得对。（B3）
4. 依次试 What to Answer、Answer/Stop、文字发送、截图提问、区域截图；截图放大和屏幕对比清晰度。（B4）
5. 失败后的"重试"；Clarify、Brainstorm、Recap、Follow Up 各点一次。（B4）
6. S46 笔试：用一道真实编程题截图提问。检查回答语言、提交框架、是否先给代码；故意贴一段报错，看能否修复；看消息框在你实际用的主题下的效果。
7. 结束会议：尾段转写收齐，会议记录里能看到这场，详情和复制可用。（B3）
8. 备用模型自动切换：只有模型不可用、限流、服务端出错、超时或断网时才会切。填错 Key 不会切，而且主备共用同一个 Gemini Key。手动很难稳定制造这些情况，碰到就记录，没碰到不勾。

### 3.5 共享保护（清单 B5，最关键）

Mac 上用整屏共享，接收端是另一台电脑上的另一个账号。Zoom 和腾讯会议各做一遍：

1. 接收端看不到启动器、会中窗口、设置窗口，也没有黑框；你在 Mac 上照常能看到和操作。
2. 共享中关掉窗口保护，接收端应该能看到窗口；再打开后立即看不到。
3. 共享中在启动器和会中窗口之间切换，接收端始终看不到。
4. 记录软件版本、共享方式、接收端看到的画面，最好拍一张接收端截图。

### 3.6 退出和再启动（清单 B6）

1. 会议进行中直接退出：**用一场可以丢弃的短会议来测**。退出成功，活动监视器里没有残留进程，也不再生成回答。退出时应用会尝试保存一次这场会议；如果保存失败，这场会议在退出时就丢了，目前不会跨重启恢复。所以不要拿重要会议来测，也不要把"没保存下来"直接记成缺陷，先看有没有保存失败的提示。
2. 辅助窗口开着时退出，不会被拦住。
3. 再次启动后，之前的设置（包括主备模型和推理强度）都在，**此前已成功保存的**会议记录也都在。

### 3.7 本轮不测

设备切换（麦克风、耳机、蓝牙）、Chrome 和飞书共享、费用上限、Windows。
