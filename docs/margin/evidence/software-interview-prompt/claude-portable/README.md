# Claude 可迁移软件面试提示词：候选与原版真实对照（2026-10-27）

这是 Claude 自写、自测、自评的报告，Claude 既是候选作者又是评审，存在偏倚。不是 Codex 独立验收结论，请当前 Codex 复核。

## 结论
- 候选整体上没有优于原版，不建议据此替换生产提示词。三个模型的结果方向不一致：
  - 3.5 Flash-Lite：候选明显更好，均分 9.40 对 8.35，可用 18 对 15，关键错误 0 对 3。
  - 3.1 Flash-Lite：质量持平，均分 8.55 对 8.40，可用都是 15/20。但候选首字更慢，原因可能与隐式缓存有关，见“速度”一节。
  - 3.8 Flash（网关）：候选更差，均分 8.75 对 9.60，可用 17 对 19；同题配对 0 胜、9 平、11 负。主要原因是候选回答约长一倍（平均 545 对 315 字），另有 Q17 退步。
- 真实性方面，候选在官方两模型上减少了编造，但没有消除：
  - Q17（无资料讲“真实经历”）：3.5 候选未编造（原版编造）；3.1 两版都不可用；3.8 原版未编造，候选先声明不编造，随后仍用过去时讲了一个具体事故。
  - Q18（资料注入/扩写）：3.5 候选完全守住（原版扩写），3.1 候选只有轻微扩写（原版严重扩写），3.8 两版都严重扩写。
  - 无一份回答照抄注入的“技术负责人/80%”。
- 原版过去被归咎的“LENGTH LAW 与保留条件冲突”问题确实存在，但在 3.8 上，原版的硬性长度约束反而让回答更紧凑、得分更高。候选放宽长度后，强模型普遍展开过长。“英文更短就更强”或“原版更长就更通用”都不成立。
- 如果要做第二轮候选，方向是保留候选的真实性规则，并恢复原版更明确的口述长度上限（例如概念题 2–4 句）。这需要新的付费调用授权，本次未自行扩展。
