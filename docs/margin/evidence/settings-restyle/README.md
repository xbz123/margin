# 设置界面改为旧 Margin 风格（2026-10-21）

基线 `44a5e3a8`，Claude 实现。用户确认的方案：颜色、布局和功能分区参考旧 Margin（`b8ade3f7`，即本机的 Margin 2.9.0）；关闭按钮放到右上角，保存方式不变，改了立即生效（用户选"甲"）。只改界面，设置项、保存流程和 IPC 都不变。

## 来源

旧 Margin 的淡紫色阶、卡片 CSS 和侧边栏选中样式，在后期上游 `f326de04` 里就有（`periwinkle` 相关 103 处，`aip-card` 67 处），属于禁用来源，没有引入。页面结构组件（页头、分组卡片、设置行）和分页方式是旧 Margin 自写的，但这次也没有复制代码：`SettingsKit` 的新组件、颜色变量和页面结构都是按需求重新写的。

旧 Margin 只作视觉参考：把 `b8ade3f7` 的设置界面源码在临时目录里打包，用同一个截图脚本渲染后对照，没有启动已安装的 Margin.app，也没有读取它的数据。

## 改动

- **颜色**：`src/index.css` 自定一套紫色强调色变量，深浅两套：主色、悬停、按下、浅底、描边、主色上的文字。深色主色 `#A994F5`，浅色 `#6C4BD3`；浅色模式的选中底色改为同色系。`tailwind.config.js` 注册新变量。
- **侧边栏**：去掉分组小标题，改成带图标的 9 页平铺列表，选中项高亮、图标用主色；"退出"留在底部；关闭按钮移到内容区右上角。
- **分页**：常规、AI 服务商、语音与音频、上下文与技能、会议记录（新）、窗口与隐私、快捷键、设置与帮助、关于。
  - "会议记录"页：从原隐私页移出"不保存会议"和调试日志。
  - "窗口与隐私"页：屏幕共享保护、鼠标穿透、界面不透明度（从常规页移入）、进程伪装。内部页名仍是 `privacy`，其他窗口用旧名打开不受影响；另加 `window-privacy` 别名。
  - "AI 服务商"和"语音与音频"保留原名称，因为帮助文字和会中提示都写的是"设置 → AI 服务商／语音与音频"。
- **统一样式**：常规、窗口与隐私、会议记录、快捷键、语音与音频五页改用"页头 + 分组卡片 + 设置行"；页面操作放在页头右上角，例如快捷键页的"恢复默认"。开关统一为一个组件，原来几个用 `div` 做的开关现在是带名称的 `switch` 按钮。
- **替换写死的蓝色**：设置页、帮助页、关于页、会议详情的用户气泡和链接、启动器的开始按钮。会中悬浮窗及其预览、服务商品牌色、Modern 悬浮窗主题的钴蓝都不动。另外修正了 4 处不生效的类名：变量颜色不能加 `/NN` 透明度，原来编译后什么都没有。
- **测试**：`settingsFoundation.test.mjs` 的页名测试改为新的 9 页和别名；新增对比度测试，深浅两套主色上的文字、以及主色文字在页面、卡片、弹层背景上都不低于 4.5:1。新增 11 条中文词条，删除 3 条不再使用的分组标题。
