- 原生 `SilenceSuppressor` 在正常静音时发送全零保活帧；`wireSystemCapture` 却在收到低振幅数据约 12 秒后报告 `mac-screen-recording-revoked-rebuild`，并不需要新的权限拒绝证据。权限允许的合成流水线可稳定复现。

- 不新增 IPC、状态机、恢复事件或 UI；静音不会再产生这条误报，也就不需要增加清除该误报的恢复链路。没有改用户文档中尚未提交的实测清单和报告。
