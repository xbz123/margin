## 发现并修正的问题

- 首次UI尝试停在合成欢迎页；沿用现有测试的首次启动处理，不修改OS权限。之后发现自动捕获必须明确绑定回答窗口，销毁时的广播须排除已销毁WebContents。
- 设置页返回时后台搜索抢焦点并遮挡控件：设置打开期间禁用后台搜索；原失败与后续实际控件通过形成回归证据。
- 首轮完整门禁失败：旧VM夹具遗漏新类型/启动调用、手动提交函数提取名变化，以及新历史预览使旧“任意图片出现”检查误通过。同步夹具并改为等待发送前附件；恢复误改的普通窗口显示调用，只在自动捕获启动时切换模式。
- 第二轮完整门禁16/16通过后，源码检查发现历史存储未保留格式标记；补齐保存/历史渲染及断言，再跑最终完整门禁16/16。
