## B. 阶段 6 实机复测（需要真实服务和设备）

### B1 启动与权限

- [ ] 冷启动到启动器出现，没有长时间卡住
- [ ] 麦克风、屏幕录制权限已授予，应用里没有重复的权限提示
- [ ] 没有配置语音转写时开始会议，会被拒绝并提示去配置；按提示能找到"语音与音频"页

### B2 配置真实服务

- [ ] 语音转写：填 Key、保存，测试连接成功。删除 Key 后不能开始会议
- [ ] 回答模型：填 Key，从列表选模型（不自动选第一个），"保存并测试"成功
- [ ] 备用模型（如有）：主模型故意填错 Key 时，能切到备用模型

### B3 会议采集

- [ ] 开始会议后，麦克风（我方）和系统音频（对方）两路转写都出现，并且分得对
- [ ] 播放一段视频或会议声音，系统音频转写正常
- [ ] 会中切换麦克风：切换后继续转写，没有卡死；选中的设备打不开时，显示改用默认设备的提示
- [ ] 会中切换输出设备（如插拔耳机或连蓝牙）：系统音频继续转写
- [ ] 结束会议：进行中的回答被取消，窗口回到启动器，尾段转写收齐（不完整时有提示）
- [ ] 会后在会议记录里能看到这场会议，详情和复制可用

### B4 回答

- [ ] What to Answer：用点击之前的双方转写回答，流式显示，可以取消
- [ ] Answer/Stop：用两次点击之间的口述内容回答
- [ ] 文字发送：不等转写，直接回答
- [ ] 截图提问和区域截图：图片发送成功；截图清晰度和屏幕原生像素一致（放大对比）
- [ ] 失败后显示"重试"，点击后用当前模型配置重新生成
- [ ] Clarify、Brainstorm、Recap、Follow Up 各点一次，都能出结果
