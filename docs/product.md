## Purpose

Margin 为笔试练习和面试交流提供桌面辅助：用户通过截图、语音和文字获得回答，面试中先得到能开口的相关内容，会后可回看本地双方转写。以已记录的 AGPL 基线重建，先交付 macOS，再实现、验收和发布 Windows，最后核对共享代码及平台差异后统一分支。

## Expectations

### 既有能力与通用边界

以下能力沿用 PLAN 的已定范围，不以 S41 增量替代全部产品范围；详细协议、安全与来源约束链接到各自文档，不在此复制实现清单。

- **AG-31、33、34 / 回答与输入**：支持截图和文字提问、笔试模式、流式显示及取消；回答支持 Gemini、OpenAI Chat、OpenAI Responses、Anthropic Messages 四协议及配置的兼容地址。Codex 登录是独立、只读的凭据来源，不是自动获得账号权益或真实服务兼容性的保证；具体边界见 [OUTBOUND](margin/OUTBOUND.md#codex-file-login-source-ag-34-local-verification)。
- **S34 / 图片**：截图按原图分辨率发送，不再缩到 1536 px；截图编码为 JPEG（质量 80），图片校验只接受 PNG/JPG，不支持 WebP/GIF。实际原生像素密度仍需实屏验证。
- **AG-40、41 / 语音**：支持麦克风和系统音频、会话开始/停止及尾段排空；云端 STT 只保留 OpenAI、Soniox、Groq（分段转写）、阿里云百炼、豆包，未配置时阻止开始。退役选择不冒充有效配置；旧 Google、Deepgram、ElevenLabs、Azure、IBM Watson STT 不恢复。
- **AG-50、S40 / Local Context**：全文随生成请求输入，不预热。只导入 UTF-8 `.md`、`.markdown`、`.txt`，不支持 PDF/DOCX。添加即同意发给所选模型服务商，卡片明确告知；删除后不再发送，不新增独立数据开关、不并入 `profile_history`、不恢复 `reference_files`。其他数据范围拒绝仍生效。
- **AG-51、S29 / 提示词与 Skills**：基础层加面试/笔试场景层，按入口选择且可手动切换；Skills 仅作提示词，不执行工具或脚本。场景附加指令只追加在默认提示词之后，不整段替换，限长、可恢复默认、只存本机。默认回答提示词保留，suggestion 不重复附加；助手身份为 Margin，不写作者，“谁开发了你”与“你是谁”使用同一固定回复。
- **AG-60、62 / 设置与引导**：界面支持英文与简体中文，提供设置、快捷键和首次启动引导。配置存在不等于真实服务、设备或共享保护已验收。
- **AG-24 / 数据安全**：保留凭据安全存储、日志脱敏、分范围出站控制、图片校验、取消与任务隔离；权限撤回后禁止后续发送，不能撤回服务商已接收的数据。具体出站、重试/备用次数及失败类型边界见 [OUTBOUND](margin/OUTBOUND.md#application-http)；本次拆分不扩大它们。
- **S1–S3、S7、S30 / 身份与交付**：正式产品为 `Margin` / `io.github.xbz123.margin`，使用独立的 Margin 数据目录，不读取旧 Natively 或 ai assistant 数据，不做旧版数据迁移。作品声明为 `AGPL-3.0-only`，各平台发布包附对应源码包及许可声明；基线与禁止引入后期上游内容的范围见 [BASELINE](margin/BASELINE.md)、[PROVENANCE](margin/PROVENANCE.md)。开发/测试身份例外与正式身份放开仍由 [PLAN](margin/PLAN.md#阶段-6-本机用户测试授权2026-10-14) 管理。

<a id="u1"></a>

### U1 · 核心场景与会后回顾

归属：AG-33、42、51、52。

核心是笔试练习与面试实时辅助，截图/语音为主要输入，文字发送保留；会后回顾只作为已采集的双方交流转写的辅助功能。继续沿用 S33 缩减后的本地列表、详情、复制，不恢复会前设置、自动摘要、标题生成、启动恢复、会议聊天或旧版完整增量保存设计。

<a id="u2"></a>

### U2 · 手动回答入口

归属：AG-42。

保留 What to answer、Answer / Stop、文字发送三种用途，不合并；Clarify、Brainstorm、Recap、Follow Up Question 保留各自功能，不恢复自动回答/Judge。面试快捷动作共用双路收尾；Answer 开始口述，Stop 结束本次口述并准备发送；顶部结束会议按钮仍走独立的会议结束流程。文字发送不等待 STT。原有取消、任务隔离不得删除；“发新消息取消旧生成”须核对真实入口，不视为现成保证。

<a id="u8"></a>

### U8 · 回答内容与真实性

归属：AG-51。

笔试给结论、解题过程，代码题给完整代码；面试优先给能先开口的相关内容，再展开。转写有歧义/资料不足时不默认中断追问，提供 1–2 个最合理方向。个人经历不能编造；数据库等未载明的选型可给 1–3 个候选和简短依据，但必须表达为建议/候选，不冒充实际使用经历。截图不清晰不作为本轮重点扩展，也不允许编造无法识别的内容。

<a id="u3"></a>

### U3 · 双路语音与片段归属

归属：AG-40、41、42。

动作触发时记录同一截止点，麦克风/系统音频并行、分别判断。优先用服务商片段标识、音频时间或收尾确认关联触发前内容；同一已开始片段在等待窗口内到达的修订必须采用最新文字，可以包含少量触发后的续句，不接入新的语音片段，不重置计时器。上限到达用现有文字（含临时文字）继续，不等句号、不增加模型调用。不能可靠关联的服务商不把任意下一条 final 当作同一句，未知状态不得伪造为已完成。

<a id="u4"></a>

### U4 · 收尾时间与完成判定

归属：AG-32、42。

两段规则保持串行：请求收尾后 IPC 响应最多 750 ms；之后，尚无 final 或仍有 interim/待完成信息时尾段最多 3 秒，已有 final 且无待完成信息时最多 1 秒。双路同阶段并行，不把两路时间相加；成功收齐可提前结束。有可靠证据确认没有待处理语音的一路可提前结束；无文字不等于静音。未知状态按原等待规则处理。阶段一已收齐的状态要保留，不能在阶段二重新等一条 final。两段配置上限为 3.75/1.75 秒，不含其余准备；实际不得超过本次首字/总时限的剩余预算。D8 已选 A：受理不等于完成，会话层统一限时收集；接口实现须保留这一区分。

**S43 / D8 的已定补充**：采用 A，保持连接、限时收集触发前已开始片段的修订，到上限用现有文字。只会结束整个任务的国内服务不因快捷动作强制 finish；会议结束仍独立 drain。不实施未选的 B 方案。

<a id="u5"></a>

### U5 · 冻结输入与迟到修订

归属：AG-40、42。

不增加转写尾段不完整标记；迟到修订可进入正常上下文和原本应保存的记录，不因此改答、补答或重发。该要求不隐藏认证、权限、模型请求失败或生成未完成等状态。音频未产出文字不能凭空补写；正常后续采集不因本次收尾而停掉。本次输入在等待实际结束时冻结（提前收齐或达到截止），不能因后续组装/排队继续吸收修订；关联范围仍以 U3 为准。

<a id="u10"></a>

### U10 · 服务商片段信息

归属：AG-41、42。

保留阿里云 `sentence_id`（旧 `id` 兼容仅作为已知格式回退）、开始/结束与音频时间信息；无文字的开始事件更新状态而非空聊天行。豆包保留片段起点/终点与定稿信息。音频相对时间必须带本连接/任务的基准，重连不得把新片段误归上一任务；实际映射方式由接口落定步骤核对。不能把 WebSocket 关闭、Promise resolve、任意 final 三者一概视为本轮完成。

<a id="u6"></a>

### U6 · 生成预算与可见首字

归属：AG-32、33、42。

面试默认首字 10 秒、总计 60 秒；笔试总计 180 秒且不套面试首字限制。三项用户可独立设置，正有限秒数，面试总计不小于首字预算。用户确认面试首字预算包含语音收尾，不能收尾后重新计满 10 秒；触发、收尾、准备、排队和自动重试/切换共用原预算。整体体验统计到 UI 第一个实际回答文字，快捷动作从点击/快捷键、口述从 Stop、文字从提交起；占位/加载/隐藏推理不算，分入口统计收尾、准备和模型至 UI 首字，不另设完整一句指标。计时跨进程须用可信关联与耗时，不接受 renderer 任意时间戳延长主进程预算。

<a id="u7"></a>

### U7 · 原输入重试

归属：AG-32、33、42。

已完成输入准备的请求失败时，提示失败并提供原输入重试。输入准备阶段的配置或图片校验失败，应修正后重新提交；快照已释放或内容已撤回时，不允许重放失效输入。用户已确认原问题、截图及当时上下文不变，不重新截图、不混入后续对话；模型/凭据等用重试时新配置，重新检查权限和图片能力，不复用旧权限决定；按 S44 不再以模型上下文容量估算拒绝请求，附件和内存硬上限仍保留。不因资料删除/权限撤回而再次发送已撤回内容（S40 仍有效）；快照与撤回冲突时不发送；本轮不扩展会中 Local Context/Skill 编辑的快照更新或删除恢复交互，也不删除既有安全校验及编辑功能。手动 Retry 点击新建任务并开始新预算；该次内部自动重试/备用共用这个预算，既有次数和失败类型限制保留。无新增模型/新配置提示文案，沿用左下角模型显示。D9 已定：只保留当前失败请求，新问题开始后释放旧快照；保留首次部分回答，重试独立结果、不拼接，关联同一原问题，不无限保存附件。

**S43 / D9 的已定补充**：快照沿现有会话/附件清理回收，不新增持久快照库。Local Context/Skill 按使用前配置处理，使用过程中不修改；会中快照更新/删除恢复交互不纳入本轮。既有安全校验、权限撤回边界与编辑功能不得删除或绕过，不新增热更新或编辑入口。不能仅凭绕过界面直接调用 IPC 的并发配置修改反例阻塞本轮验收；这不表示所有界面路径已实测锁定。

<a id="u9"></a>

### U9 · 国内语音服务配置

归属：AG-41、60。

阿里云 Workspace ID 可选：空值使用北京 DashScope 通用地址，填写时使用经校验的北京专属域名。保存、启动前置检查、设置、连接测试与生产请求必须一致，不能只改 UI。默认模型 3.1 在通用域名及长会话的可用性未实测，不承诺仅填 Key 已验证可用，不自动换模型/地域/域名。豆包资源类型贯通设置→主进程校验→安全保存→连接测试/生产：小时版 `volc.seedasr.sauc.duration`，并发版 `volc.seedasr.sauc.concurrent`，默认小时版；用户明确选，不从 Key 猜、不自动改计费资源。现有新版 Key/旧版 App ID 鉴权范围不擅自删除；本轮不新增新加坡选项，不开启二遍识别。

<a id="s44"></a>

### S44 · 回答模型配置与退出

归属：AG-60、AG-31；覆盖 U7 / S42-04 中旧的模型容量重检要求，不改变历史验收。

- 官方 API 使用内置地址，只填写 Key，模型从服务商接口获取后选择，不手填 Model ID；网关单独填写 URL/Key，提供列表时同样可选模型，不支持列表时保留手填兜底。
- 获取列表必须使用已保存、与地址绑定的凭据，不自动选择首项或保存，不在失败时冒充已从上游取得模型；地址/凭据切换后的迟到列表不得污染当前配置。原有地址变化重新输入 Key 的主进程校验不变。
- AI 提供商页面顶部集中选择主回答模型与备用模型；云端提供商卡片内配置模型及其支持的推理强度。官方模型容量依据可追溯的官方资料维护，不要求填写；自定义网关容量信息仅在对应配置下显示/填写。
- 不以模型上下文容量的前置估算拒绝请求；隐私、撤回、生成时限、附件/内存上限等安全边界保留。未知模型不伪称已知容量或推理支持，不恢复退役高级功能。
- 推理选项属于明确的提供商/协议/模型目标，贯通设置、保存、重启读取、新请求及原输入重试；已有配置缺字段时保持原请求行为。网关参数由实际协议确定，不静默丢弃、不失败后偷偷改强度、不根据同名模型假定网关支持；不支持的组合明确拒绝或不提供选项。
- 真正退出时，可见辅助窗口不得拦截关闭并留下已清理模型服务的进程；退出后禁止生成，普通关闭仍保持隐藏/返回主界面行为。
- 参数被受理不等于服务端实际采用该推理强度；真实性能与协议支持不能由设置项或模拟测试推定。

<a id="u11"></a>

### U11 · 窗口保护与共享

归属：AG-61、62、72。

Chrome、Zoom、腾讯会议、飞书整屏共享：接收方不出现主入口和会话辅助窗，本机仍可用。鼠标穿透是独立自选开关，不产生意外弹窗。不强制隐藏进程，保留既有伪装；Mac/Windows 图标分别设计，视觉方案待定，不引入未经来源审查的资产。README 只写已实测的 OS/软件版本、共享方式和结果，不新增运行时环境检测/禁用机制，不保证未测环境。黑框不可接受；助手及其黑框替代物均不得出现在远端画面。

<a id="u12"></a>

### U12 · 平台与发布顺序

归属：AG-62、70–75。

先 Mac 发布，再 Windows 实现/验收/发布，最后检查共享代码、平台差异与双平台回归再定分支统一方式。Mac 实现不把共享业务写死到 Mac API；不为未知平台造新框架，不撤销 S30 的来源边界。普通逐票 CI 按 S43 已授权；发布、实机及阶段签收不因此自动批准。

## Non-goals

- 不恢复 S6/S33/S39 退役的 premium、natively-api、遥测、自动更新、RAG/embedding、Ollama 管理、本地 STT/模型下载、手机镜像、日历、cURL 模板、Profile Intelligence、premium 模式、动态动作、联网搜索、OCR、跟进邮件、捐赠/支持弹窗及退役 STT；删除功能而非隐藏入口。兼容地址仍可配置，不据此禁止用户自行运行的兼容服务。
- 不恢复自动回答/Judge、Local Context 预热、会前设置、自动摘要/标题、启动恢复、会议聊天或旧版完整增量保存设计。
- 不新增语义完整性模型、进程级不可检测承诺、运行时兼容性封锁或持久重试快照库；不做旧版数据迁移。
- 不把文档拆分当成应用实现、真实服务/采集、发布、创建 PR 或远程 issue 的授权；既有单项授权继续按 PLAN 的范围生效。

## Acceptance boundaries

<a id="u13"></a>

### U13 · 验证层次与证据

归属：各变更所属票。

优先复用既有测试，变更语义才调整、实际缺口才补最小检查。普通 CI 用模拟 STT/LLM 的行为测试及真实按钮/IPC/renderer 消费链，不读真实凭据、不计费；真实服务固定音频/问题测量与少量实机另按 D2 授权。样本组合、数量及 P50/P95 达标线未定，曾提的 36 次方案未批准；模拟耗时不代表真实质量/服务延迟。

优先观察设置→IPC→保存→实际适配器请求、动作→会话→生成→界面消费的外部行为，沿用隔离测试、不新建框架。非法资源保存、测试/生产资源不一致、新片段混入冻结输入、收尾重新获得整段首字预算、撤回内容重发等反例必须失败。模拟测试不证明真实转写质量、响应延迟或共享不可见；技术验收不代替用户签收。具体执行门禁和结果见 [PLAN 验收](margin/PLAN.md#5-验收)及[阶段 6 签收标准](margin/PLAN.md#阶段-6-验收标准与当前结果)。

- **D2 / 真实验收**：未覆盖的真实服务与实机测试组合、执行人、样本数、费用范围及 P50/P95 达标线待定；阻塞对应真实质量、延迟、设备和共享保护结论，不阻塞模拟契约实现。既有 S44 真实参数测试及本机测试授权不因整理而失效，也不扩展到其他服务或数据，见 [S44 授权](margin/PLAN.md#s44-settings)。
- **D7 / 发布架构**：尚未定案。`(proposed)` macOS arm64、Windows x64；Intel Mac / Windows on ARM 需额外构建与验收。阻塞相应架构的发布范围，不把已有测试包架构当成产品支持承诺。
- **D6 / 签名**：是否使用 macOS Developer ID 签名/Apple 公证及 Windows 代码签名待用户决定；阻塞相应签名交付，不阻塞按既有规则允许的未签名首次发布。未签名下载者会遇到 Gatekeeper / SmartScreen 警告，不能冒充已签名。
- **U11 / 图标视觉**：Mac/Windows 分别设计已定，具体视觉方案待确认；阻塞对应图标制作，不阻塞独立文档整理。
- **AG-62 / 正式身份与发布**：正式 Margin 身份的放开方式、何时在本机使用及每次发布授权仍由用户决定；既有 Natively Local 测试例外不代替正式身份或发布批准。
- **U12 / 分支统一**：先 Mac、后 Windows、最后统一分支的顺序已定；具体分支/合并方向在共享代码、平台差异与双平台回归核对后决定，不阻塞 Mac 首发。
